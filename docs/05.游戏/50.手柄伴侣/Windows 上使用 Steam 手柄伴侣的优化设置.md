Windows 上使用 Controller Companion 时，建议先关掉两个容易和手柄输入冲突的系统功能，这样桌面操作会更稳定，也更少误触。

## 使用体验优化

1. **Windows Game Bar 设置**
   - 按 `Win + G` 打开 Game Bar。
   - 进入「设置」→「更多设置」→「输入」。
   - 关闭「使用手柄上的 Xbox 按钮打开 Game Bar」。

2. **Steam 控制器设置**
   - 打开 Steam 的「设置」→「控制器」。
   - 进入「显示高级设置」。
   - 关闭「启用控制器的导航组合键」。

## 说明

这两个设置的目标都是减少系统级快捷键和控制器输入之间的冲突。关闭后，Controller Companion 在桌面场景里会更接近“纯鼠标键盘辅助输入”的体验。
